=========================================================
 PRUEBAS MANUALES: COMANDOS ADMINISTRATIVOS DEL CHAT IA
=========================================================
Proyecto: Soluciones Edgar
Fecha: 2026-06-05

Instrucciones:
1. Inicia sesión como administrador en /admin
2. Abre el chat en /ia-chat o en el panel administrativo
3. Copia y pega cada pregunta, una por una
4. Verifica el resultado esperado

=========================================================
 PRUEBA 1: Reporte de Cierre
=========================================================
Pregunta: "reporte de cierre"
Resultado esperado:
- El sistema responde "Reporte generado correctamente"
- Incluye un enlace como http://127.0.0.1:8000/storage/reports/reporte-cierre-pedidos-*.txt
- El enlace DEBE abrir el archivo en el navegador
- Si no abre: ejecuta "php artisan storage:link"

=========================================================
 PRUEBA 2: Reporte del Último Trámite
=========================================================
Pregunta: "genera un reporte del último trámite"
Resultado esperado:
- Genera reporte con solo 1 trámite (el más reciente)
- El enlace debe abrir en el navegador

=========================================================
 PRUEBA 3: Crear Trámite (Todos los datos)
=========================================================
Pregunta: "Crea un trámite de Acta de Nacimiento para Luis Alfonso con CURP EXPL050202HYNKCSA0"
Resultado esperado:
- Crea el pedido REAL en la base de datos
- Responde: "Pedido creado correctamente. ID: #N..."
- NO debe dar instrucciones inventadas
- Verificar en /admin/orders que el pedido existe

=========================================================
 PRUEBA 4: Crear Trámite de CURP
=========================================================
Pregunta: "Crea un trámite de CURP para Ana López con CURP LOAA010203MYNPRA09"
Resultado esperado:
- Busca el servicio "CURP Actualizada" por alias
- Crea el pedido real
- Responde confirmación
