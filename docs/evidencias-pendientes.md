# Evidencias Pendientes

Esta lista enumera las evidencias que aún requieren confirmación manual o análisis adicional:

- Verificación manual del flujo de voz (Web Speech API) conectado al campo de chat real.
- Confirmación visual de los estados UI `SEARCHING`, `THINKING`, `STREAMING` en diferentes navegadores.
- Prueba de recuperación de conversación después de reiniciar la aplicación.
- Validación de que una desconexión no guarda respuestas incompletas como exitosas.
- Revisión del guardrail contra patrones de jailbreak muy específicos.

No se inventan resultados; los puntos requieren pruebas manuales o auditoría de logs.
